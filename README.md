# 🏠 CampusNest Roommate Finder

A full-stack student housing platform that helps students find verified accommodations and compatible roommates without relying on brokers.

## 🚀 Overview

CampusNest simplifies the student housing experience by connecting students directly with landlords and potential roommates through a modern web platform.

The platform provides property discovery, roommate matching, landlord verification, and secure subscription-based access, creating a trusted housing ecosystem for students.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/priyansh-27/campusnest-roommate-finder.git
```

### Backend Setup

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
